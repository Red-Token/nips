# Proposals

Text written to be sent to another project's specification, kept here
whether or not it has been sent.

| | Against | Status |
|---|---|---|

Both are the two things [`../nwc-bip321.md`](../nwc-bip321.md) adds to
NWC-321. They were drafted by mission 26.1 and deliberately not submitted;
the mission's outcome records that decision.

**If they are sent**, the period after which no answer is itself the
answer is **four weeks** — a number fixed before submission rather than
after, so that waiting cannot quietly become the outcome. The repository
merges within days when active, so four weeks is generous by its own
standard and cannot read as pressure.

They are kept because a proposal that exists is a different thing from one
that was never written. `nwc-bip321.md` is a local extension of somebody
else's specification, and the case for it being upstream is worth having
written down — whoever revisits it, and whenever.
